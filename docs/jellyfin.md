# Media Server Now Playing (Jellyfin / Plex) 0.2.0

**UNTESTED.** Not yet run on a real Composer or Director. The Plex backend is entirely unverified against a real Plex server.

One driver (`drivers/jellyfin`, package `c4z/jellyfin.c4z`) for Jellyfin or Plex. It polls the server for the active playback session, publishes the now-playing data as driver variables, and sends transport commands to that session.

## Setup

1. Add the driver in Composer and set **Server Type** to `Jellyfin` or `Plex`.
2. **Server URL**
   - Jellyfin default: `https://jellyfin.onyxlens.com` (server "Shalai").
   - Plex: enter the server address, for example `http://<plex>:32400`. The default URL is Jellyfin's, so change it when Server Type is Plex.
3. **API Key / Plex Token**
   - Jellyfin: an API key from the Jellyfin dashboard.
   - Plex: your X-Plex-Token.
   - This is a plain text property. Composer cannot mask it.
4. Optional: **Target User Or Device Filter** (matches user, device or client name), **Poll Interval Seconds** (2 to 60, default 4), **Allow Self-Signed TLS**, **Debug Log**.
5. Run **Test Connection**. **Status** shows the result.

## How each backend works

| | Jellyfin | Plex |
|---|---|---|
| Sessions | `GET /Sessions` | `GET /status/sessions` |
| Auth | `Authorization: MediaBrowser Token="..."`, falls back to `X-Emby-Token` once on 401/403 | `X-Plex-Token` header |
| Transport | `POST /Sessions/{id}/Playing/{Cmd}` | `GET /player/playback/{cmd}` with `X-Plex-Target-Client-Identifier` (the player's machineIdentifier) and a `commandID` counter |
| Test | `GET /System/Info` | `GET /identity` |

Plex artwork is `{Server URL}{thumb}?X-Plex-Token=...`. That URL contains the token, and it is visible in the Artwork URL variable.

## Variables

Play State, Session Id, Now Playing Title, Now Playing Subtitle, Now Playing Summary, Artist, Year, Media Type, Position, Position Seconds, Runtime, Runtime Seconds, Client, Device, User, Artwork URL, Item Id.

## Commands

Play/Pause, Play, Pause, Stop, Next, Previous, Seek To Percent (0 to 100). Actions: Test Connection, Refresh Now.

## Events

1 Play State Changed, 2 Playback Started, 3 Playback Stopped, 4 Now Playing Item Changed.

## Icons

`www/icons/device_sm.png` (16x16) and `device_lg.png` (32x32). These are simple original icons (a rounded square with a play triangle). They contain no brand logos or trademarks. They are generated by a stdlib-only script, not copied from any product.
