Moen Smart Shower (U by Moen)

Driver version 301 · unofficial driver, not affiliated with Moen, Fortune Brands or Control4

Controls a U by Moen digital shower valve from Control4. The driver signs in to the Moen cloud with the homeowner's U by Moen account, reads the shower's state, and sends commands over Moen's real-time channel. It runs entirely on the Control4 controller; no extra computer is needed.

It gives you three ways to run the shower:

  • A Shower tile in Navigator that opens a full shower page: live water temperature, Start/Stop, the presets, a temperature control and outlet buttons.
  • Keypad keys bound directly to the driver: one key per preset plus a Shower key, with LEDs that turn amber while the water warms and green when it's ready.
  • Composer programming: commands, actions, variables and events.

Before you install

This replaces earlier versions of this driver (v204 and older used a thermostat-style device; package name Moen_Smart_Shower_Standalone_driver_v200.c4z). Composer can't change a device from a thermostat to a button in place, so delete the old Moen device and add this one as a new device. Any programming that used the old device has to be redone. From this version on the package is always named moenshower.c4z, so future updates install in place with Add or Update Driver.

You need:

  • The U by Moen account email and password the shower is registered to.
  • Presets already set up in the U by Moen phone app (see Presets).
  • Internet access on the controller (the shower is controlled through Moen's cloud).

Setup

  1. Add moenshower.c4z to the room the shower is in.
  2. In Properties, enter Moen Account Email and Moen Account Password.
  3. Within about a minute, Cloud Status should read Authenticated and Pusher Status Connected / subscribed. Leave Device Serial Number Override blank unless the account has more than one shower.
  4. Run the Print Debug Info action and check the Lua output: it lists the presets the driver found, with their position numbers.
  5. If the Shower tile doesn't appear in Navigator under Comfort, open the room's Navigator settings in Composer and make sure the Shower button is shown.
  6. Open the Shower tile once on a touchscreen or the app. Web Page Status should read Page build 1 OK.
  7. Bind keypad buttons if you want them (see Keypad keys), then refresh Navigators.

Presets

Presets are created and edited only in the U by Moen phone app. Each one stores a name, temperature, which outlets run, an optional timer, and what happens at temperature (pause the water, chime, notify). They live in the shower and Moen's cloud. This driver reads the list live, so a preset added or renamed in the app shows up on the Shower page on the next status check. The driver cannot create, edit or delete presets.

Each preset has a position number in the app's list. Keys, commands and actions refer to presets by that number. Print Debug Info shows the numbers.

The Shower page (Navigator)

PartWhat it does
Temperature ringThe large number is the water temperature now. While running, the ring fills toward the set temperature and changes from blue to amber as the water warms. The dot on the ring marks the set temperature. Under the number: Off, Warming up, Ready, or Paused at temperature.
Start / Stop showerStart turns the water on with the shower's current settings (or resumes a paused preset). Stop turns it off.
Resume waterAppears only when a preset has paused the water at temperature.
− / +Changes the set temperature 1° per tap. Works only while the water is running. The change is sent 0.7 s after the last tap.

Opening, closing or refreshing the page never turns water on. Only Start, a preset row, or an outlet button does.

Keypad keys

Bind keypad buttons on the Connections tab, with no programming. Each connection can take buttons from several keypads. Delete any old shower programming on those buttons first, or it will fight with the driver.

ConnectionTapHold (1 s)
Preset Key 1–4 Shower off: starts that key's preset.
That preset running: stops the shower.
That preset paused at temperature: resumes the water.
A different preset running: does nothing (see If Another Preset Is Running).		 Stops the shower.
Shower Key Shower off: starts the last-used preset.
Running: stops the shower.
Paused at temperature: resumes the water.		 Stops the shower.

Which preset a Preset Key starts is set by Preset Key N Preset (defaults: key 1 = preset 1, and so on). A key whose preset position doesn't exist in the Moen app does nothing.

Key LEDs

LEDMeaning
WarmingThis key's preset is running and the water is heating up.
ReadyThe water is at temperature (running, or paused and waiting).
IdleShower off, or a different preset is running.

The Shower Key lights for any running preset. LEDs change the moment a key is pressed, then follow the shower's real state. The shower is checked every 4 s while running and every 20 s while off, so a change made in the Moen app or at the shower can take that long to show. Colors are set by Idle Color, Warming Color and Ready Color.

Starting the shower from outside the bathroom

With Keypad Pause When Ready set to Yes (the default), a preset started from a keypad is sent with "pause water when ready" on: the valve heats the water, stops at temperature, and the key turns green. Step in and tap the key (or Resume on the shower) to start the water. With it set to No, the water keeps running from the moment the key is pressed.
  • Only a tap ever starts water. A hold always stops it.
  • While one preset is running, other Preset Keys do nothing, so a tap elsewhere can't change the temperature on someone in the shower. Change If Another Preset Is Running to Switch to this preset if you want them to switch.
  • The page and Composer actions do not force the pause; they use the preset exactly as saved in the Moen app.

Events

EventFires when
Shower StartedThe water turns on.
Shower ReadyThe water reaches the set temperature. Good for an announcement in the bedroom.
Shower StoppedThe water turns off.

Events fire on changes only, never on the first status after the driver loads. Because the shower is checked every 4 s while running, an event can arrive up to about 4 s after the change.

Check on the first install

These parts are built on what's known about Moen's service but haven't been run on a real shower yet:

  • Pause when ready from a keypad. Start a preset from a key, confirm the water stops at temperature and the key turns green, then confirm Resume starts it. Also open the preset in the Moen app afterwards and check whether "pause when ready" is now saved on the preset itself. If it is, set Keypad Pause When Ready to No and turn the setting on in the app instead.
  • Paused at temperature state (the Resume button, green LED while paused). Moen calls this mode paused-by-preset; it hasn't been seen live.
  • Key bindings. The key handling is the same as other AnacommSystems keypad drivers, but hasn't been bound to this driver yet.

Troubleshooting

ProblemWhat to do
No Shower tile in NavigatorCheck the room's Navigator settings in Composer, then refresh Navigators. The package must be named exactly moenshower.c4z; Navigator hides the tile if the page can't be found.
Page shows "Can't reach the shower"Check Cloud Status and Pusher Status. A wrong password shows as an authenticate error and retries every 15 s.
Page looks out of date after an updateWeb Page Status says PAGE IS STALE. Close the Control4 app completely and reopen it.
Page says "Connecting" foreverSet Log Mode to Print, reopen the page, and check the Lua tab for UI_HELLO. If it never appears, the page isn't reaching the driver.
A key does nothingSet Log Mode to Print and tap it. The Lua tab says why (for example, another preset is running, or the preset position doesn't exist).
Key LED stays darkRun Repaint Key LEDs. If that doesn't help, unbind and rebind the button.
Water turns on, then straight offOld Composer programming on the same button is also firing. Remove it.
Commands are slow or missedPusher Status must read Connected / subscribed. Commands sent before that wait up to 10 s, then are dropped and logged.
